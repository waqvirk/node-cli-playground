# node-cli-playground
A Node.js CLI project built to strengthen JavaScript fundamentals through three interactive terminal applications — Designed as a clean, modular, and portfolio-ready showcase of logic building, text manipulation, and command-line interaction.

📂 Project Overview

This project includes three command-line programs, each accessible via node commands and powered by process.argv for input handling:

1. Rock Paper Scissors

2. Pig Latin Translator

3. Caesar Cipher Encryption Tool

Each program runs directly in the terminal and outputs results instantly.

🚀 How to Run

Clone the repo and navigate into the project folder:

git clone https://github.com/waqvirk/node-cli-playground.git
cd node-cli-playground

Run each program with:

node filename.js <arguments>

🎮 1. Rock Paper Scissors

Play a classic game in your terminal.

▶ Usage
node rockPaperScissors.js rock

📌 Example Output
You chose rock.
Computer chose scissors.
You win!

🐷 2. Pig Latin Translator

Convert English text into Pig Latin using simple linguistic rules.

▶ Usage
node pigLatin.js "Pig Latin is fun"

📌 Example Output
Igpay Atinlay isway unfay

🔐 3. Caesar Cipher Encryption

Shift letters in a phrase using the classic Caesar Cipher algorithm.

▶ Usage
node caesarCipher.js "hello world" 3

📌 Example Output
khoor zruog


Supports:

Positive and negative shifts

Case-insensitive input

Alphabet wrapping (z → a)
